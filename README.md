# Atelier Judaica

אתר אמן בעברית וב־RTL המשלב תדמית, פורטפוליו וקטלוג עם סל פנייה ב־WhatsApp. Next.js 16.4.3, React 19.3, TypeScript וייצוא סטטי. הפרויקט מקומי ולא פורסם לשירות אחסון.

## הפעלה

נדרש Node.js נתמך (20.9 ומעלה) ו־npm. ב־Windows PowerShell ניתן להשתמש ב־`npm.cmd` במקום `npm`.

```sh
npm ci
npm run dev
```

תצוגה: http://127.0.0.1:3000

```sh
npm run build
npm run preview
```

הבנייה מפיקה את `out/`, מוכנה לאחסון סטטי. שרת התצוגה תומך ב־gzip וב־cache לקבצים סטטיים. ניתן להגדיר פורט באמצעות `PORT` וכתובת בדיקה אחרת באמצעות `PREVIEW_URL`.

## העיצוב והצילומים

העיצוב משלב ירוק עמוק, זהב ושנהב, פתיח צילומי גדול, גלריה במבנה מגזין, קטלוג וסיפור העסק. יש חותם טיפוגרפי המסתובב סיבוב מלא, רצועת טקסט נעה, תנועת צילום עדינה, הופעת תוכן בגלילה והטיית צילום בעכבר. אלו אפקטים ב־CSS ו־JavaScript מקומי; לא נכללו ספריית אנימציה או מנוע תלת־ממד. האפקט אינו צילום מוצר אמיתי מכל זוויותיו.

כפתור השהיית תנועה נמצא בתחתית האתר. העדפת מערכת להפחתת תנועה מכובדת, והתוכן נשאר זמין גם כש־JavaScript כבוי.

הצילומים אמיתיים, מהאוסף החינמי של Unsplash, ומוגשים מקומית כ־WebP. הם צילומי אווירה והשראה בלבד, ואינם מציגים עבודות, מוצרים או סטודיו של אסתר. הדבר מצוין באתר, בקטלוג ובפניות. מקורות וקרדיטים: `/photo-credits/` ו־`public/images/credits.json`.

תמונת הפתיח כוללת גרסה קטנה לנייד. יתר התמונות כוללות גדלים 96–1000 פיקסלים, עם בחירה אוטומטית לפי המסך. הגופנים מקומיים, ללא פנייה ל־Google Fonts; רישיונותיהם מצורפים ב־`public/`.

## תוכן והחנות

פרטי העסק, פרטי הקשר ונתוני הקטלוג נמצאים ב־`src/data/site.ts`. אפשר לסנן את הקטלוג, לפתוח צילום במבט מקרוב, לבחור כיווני השראה ולהוסיף או להסיר אותם מסל הפנייה. הפנייה ל־WhatsApp כוללת את שמות הבחירות והבהרה שהתמונות להשראה. הבחירה נשמרת בזיכרון העמוד בלבד; רענון מאפס אותה.

אין מחירים מומצאים, חיוב או הבטחה לזמינות. זהו קטלוג לפנייה אישית ולא מערכת סליקה. כדי להפוך אותו לחנות מכירה יש לספק מוצרים ותמונות מאושרים, מחירים, תנאי מכירה ומשלוח ופרטי ספק תשלום.

הטופס בודק שם והודעה כשדות חובה, וטלפון אופציונלי. הוא פותח הודעה מוכנה ב־WhatsApp; המבקר שולח אותה בעצמו. מוצג קישור חלופי אם פתיחת החלון נחסמת. אין שמירת פניות, שליחת מייל, אנליטיקה או אחסון פרטי קשר באתר.

## החלפת תמונות ותמונת שיתוף

להחלפת צילום שמרו קובץ ב־`public/images/` ועדכנו את הנתונים וקרדיט הצילום. עבור ארבעת צילומי ההשראה הקיימים, הפיקו גדלים מחדש באמצעות:

```sh
node scripts/resize-photos.mjs
```

הגדלים חייבים להימצא לפני בנייה; הם נכללים בפרויקט. ה־loader ב־`src/lib/image-loader.ts` משתמש בגדלים המוכנים רק לשמות הצילומים המוגדרים בו. תמונה חדשה עם שם אחר תוגש מהמקור; להכנתה לטעינה רספונסיבית יש להוסיף אותה לרשימת העיבוד ול־loader יחד. כלי העיבוד משתמשים ב־sharp המותקן עם Next.js.

`scripts/download-photos.mjs` משחזר את צילומי המקור ודורש גישה לרשת. יש להריץ אחריו את `resize-photos.mjs`. המקור לתמונת השיתוף הוא `public/social-card.svg`; הפקת PNG מחדש עם Chrome מקומי:

```sh
node scripts/generate-card.mjs
```

## SEO ופרסום

העתיקו את `.env.example` ל־`.env.local`. הגדירו `NEXT_PUBLIC_SITE_URL` לכתובת HTTPS האמיתית של האתר, ללא נתיב. הגדירו `CONTENT_APPROVED=true` רק לאחר אישור התוכן, ובנו מחדש.

אינדוקס מופעל רק כששני התנאים מתקיימים. עד אז: `noindex, nofollow`, חסימת סריקה ב־robots ומפת אתר ריקה. לאחר הגדרת דומיין ואישור, נוצרים canonical, כתובות שיתוף, מפת אתר וקובץ robots המתיר סריקה. אין דומיין מומצא או דירוגים וביקורות מומצאים ב־Schema.

האתר כולל מטא־דאטה בעברית, Open Graph, תמונת שיתוף, Twitter Card ו־Schema מסוג Organization ו־WebSite. יש להשלים צילומי מוצרים, ביוגרפיה, תנאי מכירה ומשלוח והצהרת נגישות לפני פרסום לציבור. ציון Lighthouse מקומי אינו מבטיח דירוג חיפוש או ציון PageSpeed באתר המפורסם.

## בדיקות

```sh
npm run typecheck
npm test
npm run build
npm run preview
# בטרמינל נוסף, כאשר התצוגה פועלת:
npm run test:browser
npm run test:catalog
npm run audit
```

הכלים משתמשים ב־Chrome המקומי דרך Playwright, ללא התקנת דפדפן נוסף. בדיקות הדפדפן מניחות טיוטה חסומה לאינדוקס. נבדקים RTL, נגישות ב־axe, רוחבים 320–1440 פיקסלים, נכונות קישורים, טופס, מקלדת, תפריט נייד, תמונות, חלונות קטלוג, סל פנייה, העדפות תנועה ועמודי המידע. בדיקות WhatsApp אינן שולחות הודעות.

תוצאות וצילומי מסך נשמרים ב־`reports/`, שאינה נכללת במעקב Git. תוצאות הבדיקה האחרונות מפורטות ב־`VALIDATION.md`.
