# רימון — יודאיקה בצבע אחר

אתר יודאיקה עברי ב־RTL עם מיתוג עצמאי, גלריה, קטלוג השראה, רשימת בחירות ואזור הכנת פנייה. Next.js 16.4.3, React 19.3, TypeScript וייצוא סטטי.

## הפעלה

```sh
npm ci
npm run dev
```

תצוגה ב־http://127.0.0.1:3000. ב־Windows אפשר להשתמש ב־`npm.cmd`.

```sh
npm run build
npm run preview
```

תוצרי הבנייה בתיקיית `out/`, מוכנים לאחסון סטטי. לא בוצע פרסום לאחסון במסגרת העדכון הזה.

## תוכן, תמונות ומיתוג

נתוני הקטלוג והתוכן בקובץ `src/data/site.ts`. הלוגו הווקטורי נמצא ב־`src/components/brand-logo.tsx` והסמל ללשונית ב־`public/icon.svg`. העיצוב משלב כחול קובלט, קורל, צהוב וקרם, עם אנימציות קלות ותמיכה בהפחתת תנועה.

כל שבע התמונות נוצרו מחדש עבור הפרויקט באמצעות כלי image_gen המובנה: צילום סגנוני לפתיח, פמוטים, גביע קידוש, בית מזוזה, חמסה, צלחת רימון ואמנות גאומטרית בהשראת ירושלים. אלו הדמיות מקוריות, לא צילומים של מוצרים קיימים או מלאי. הנחיות היצירה המלאות מתועדות ב־`public/images/rimon/sources.json`. קובצי WebP והגרסאות הרספונסיביות נמצאים ב־`public/images/rimon/`. אין טעינה מרשתות חברתיות או שימוש בצילומי יוצר חיצוני.

להפקת גדלים ותמונת שיתוף מחדש:

```sh
node scripts/resize-photos.mjs
node scripts/generate-card.mjs
```

כלי המדיה משתמשים ב־sharp המותקן עם Next.js וב־Chrome המקומי. הגופנים מקומיים; רישיונותיהם בתיקיית `public/`.

התמונות נטענות כ־WebP בגדלים רספונסיביים, לתאימות גם לתצוגות מוטמעות שאינן מפענחות AVIF. נשמרו גם חלופות AVIF. להפקת WebP בלבד אפשר להריץ `node scripts/resize-photos.mjs --webp-only`.

## בחירות ופניות

הקטלוג מאפשר סינון, הגדלת פריט והורדת רשימת בחירות כקובץ טקסט. הטופס בודק שם והודעה כחובה וטלפון אופציונלי, ומכין טקסט להעתקה או לשמירה מקומית. אין שליחת הודעות, יעד קשר מוגדר, שמירת מידע בשרת, סליקה, מחירים או טענות למלאי. בחירות נשמרות בזיכרון העמוד ורענון מאפס אותן.

לפני השקת חנות פעילה יש להוסיף פרטי עסק וקשר מאושרים, דומיין, קטלוג מוצרים אמיתי, תמונות מוצר, מחירים, תנאי משלוח ומכירה והצהרת נגישות מלאה. להפעלת תשלום יידרש חיבור מתאים לספק סליקה.

## SEO ושיתוף

העתיקו את `.env.example` ל־`.env.local` והגדירו `NEXT_PUBLIC_SITE_URL` לדומיין HTTPS החדש, ללא נתיב. רק לאחר אישור התוכן הגדירו `CONTENT_APPROVED=true` ובנו מחדש. עד אז האתר מסומן `noindex, nofollow` ומפת האתר ריקה. ללא דומיין לא נוצרת כתובת שיתוף משוערת או מקומית. לאחר הגדרה תגיות Open Graph ו־Twitter מפנות לתמונת `public/rimon-share.jpg` בגודל 1200×630. Schema כולל את שם המותג והתיאור בלבד, ללא פרטי קשר או הצעות מכירה מומצאים.

```sh

npm run build
npm run test:sharing
npm run preview
# בטרמינל נוסף:
npm run test:browser
npm run test:catalog
npm run test:images
npm run audit
```
