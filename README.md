# Atelier Judaica

אתר אמן בעברית וב־RTL המשלב תדמית, פורטפוליו וקטלוג עם סל פנייה ב־WhatsApp. Next.js 16.4.3, React 19.3, TypeScript וייצוא סטטי. האתר הציבורי נמצא ב־https://atelierjudaica.mybizsite.co/; שינויי הקוד המקומיים דורשים בנייה ופרסום מחדש באחסון.

## הפעלה

נדרש Node.js נתמך (20.9 ומעלה) ו־npm. ב־Windows PowerShell ניתן להשתמש ב־`npm.cmd` במקום `npm`.

```sh
npm ci
npm run dev
```

תצוגה: http://127.0.0.1:3000

```sh
npm run build
npm run preview
```

הבנייה מפיקה את `out/`, מוכנה לאחסון סטטי. שרת התצוגה תומך ב־gzip וב־cache לקבצים סטטיים. ניתן להגדיר פורט באמצעות `PORT` וכתובת בדיקה אחרת באמצעות `PREVIEW_URL`.

## העיצוב והצילומים

העיצוב משלב לבן חם, בז׳ וזהב, בהתאמה ליצירות האמיתיות של אסתר. הפתיח והגלריה מציגים מפות ישראל, אותיות וסמלים בטקסטורה. יש חותם טיפוגרפי המסתובב סיבוב מלא, רצועת טקסט נעה, תנועת צילום עדינה, הופעת תוכן בגלילה והטיית צילום בעכבר. אלו אפקטים ב־CSS ו־JavaScript מקומי, ללא ספריית אנימציה או מנוע תלת־ממד. האפקט אינו צילום יצירה מכל זוויותיה.

כפתור השהיית תנועה נמצא בתחתית האתר. העדפת מערכת להפחתת תנועה מכובדת, והתוכן נשאר זמין גם כש־JavaScript כבוי.

הצילומים נלקחו מהפרופילים הציבוריים של Atelier Judaica ב־Instagram וב־Facebook שסיפק המשתמש. מוצגות שש עבודות מקוריות, תקריב טקסטורה וצילום של אסתר עם יצירה שלה. פרטי המקורות מופיעים ב־`/photo-credits/`, בקישור מתוך כל עבודה וב־`public/images/atelier/sources.json`. הזכויות ביצירות ובצילומים נשארות אצל בעליהן.

תמונת הפתיח כוללת גרסת AVIF קטנה לנייד ו־WebP לגיבוי. יתר התמונות כוללות גדלי AVIF של 96–1000 פיקסלים, עם בחירה אוטומטית לפי המסך. הגופנים מקומיים, ללא פנייה ל־Google Fonts; רישיונותיהם מצורפים ב־`public/`.

## תוכן והחנות

פרטי העסק, פרטי הקשר, התמונות, קישורי הפרופילים ונתוני הקטלוג נמצאים ב־`src/data/site.ts`. אפשר לסנן לפי מפות ישראל או מילים וסמלים, לפתוח צילום במבט מקרוב ולהוסיף או להסיר עבודות מסל הפנייה. הפנייה ל־WhatsApp כוללת את שמות העבודות ואת הקישורים לפרסומים המקוריים. הבחירה נשמרת בזיכרון העמוד בלבד; רענון מאפס אותה.

מחירים וזמינות נמסרים ישירות על ידי אסתר. זהו קטלוג לפנייה אישית ולא מערכת סליקה. כדי להוסיף רכישה באתר יש לספק מחירון מאושר, תנאי מכירה ומשלוח ופרטי ספק תשלום. המידות 60×60 ס״מ ליצירת חי ו־80×80 ס״מ ליצירת אהבה, והמידע על עלי הזהב והחול הישראלי ביצירת אהבה, מבוססים על הפוסטים המקוריים בלבד. לא הוסקו מידות או חומרים עבור יתר העבודות.

הטופס בודק שם והודעה כשדות חובה, וטלפון אופציונלי. הוא פותח הודעה מוכנה ב־WhatsApp; המבקר שולח אותה בעצמו. מוצג קישור חלופי אם פתיחת החלון נחסמת. אין שמירת פניות, שליחת מייל, אנליטיקה או אחסון פרטי קשר באתר.

## החלפת תמונות ותמונת שיתוף

להחלפת צילום שמרו מקור WebP ב־`public/images/atelier/`, ועדכנו את הנתונים, המידות ומקור הצילום. עבור תשעת הצילומים הנוכחיים, הפיקו גדלים מחדש באמצעות:

```sh
node scripts/resize-photos.mjs
```

הגדלים חייבים להימצא לפני בנייה; הם נכללים בפרויקט. ה־loader ב־`src/lib/image-loader.ts` משתמש בגדלים המוכנים רק לשמות הצילומים המוגדרים בו. תמונה חדשה עם שם אחר תוגש מהמקור; להכנתה לטעינה רספונסיבית יש להוסיף אותה לרשימת העיבוד ול־loader יחד. כלי העיבוד משתמשים ב־sharp המותקן עם Next.js. אין טעינה חיה משרתי הרשתות החברתיות בזמן הגלישה.

צילומי המקור הנוכחיים כבר כלולים בפרויקט. לעדכון עתידי יש לספק מקור מקומי או לייבא צילום מהפרסום המקורי בהתאם להרשאה. המקור לתמונת השיתוף הוא `public/social-card.svg`; הפקת JPEG לשיתוף ו־PNG עם Chrome מקומי:

```sh
node scripts/generate-card.mjs
```

תגיות השיתוף מפנות ל־`/atelier-judaica-share.jpg`: צילום עבודה מקורית עם מיתוג, בגודל 1200×630 פיקסלים ובמשקל כ־121KB. הכתובת הציבורית נלקחת מ־`NEXT_PUBLIC_SITE_URL` כשמוגדר ערך תקין; אחרת נעשה שימוש בדומיין המאומת שב־`site.publicUrl`. כך אין הפניה לכתובת מקומית גם בבנייה ללא משתני סביבה. במעבר לדומיין אחר יש לעדכן גם את ברירת המחדל. לאחר פרסום מחדש ייתכן שתצוגה מקדימה קודמת תישאר במטמון של שירות השיתוף.

## SEO ופרסום

העתיקו את `.env.example` ל־`.env.local`. הגדירו `NEXT_PUBLIC_SITE_URL` לכתובת HTTPS האמיתית של האתר, ללא נתיב. הגדירו `CONTENT_APPROVED=true` רק לאחר אישור התוכן, ובנו מחדש.

אינדוקס מופעל רק כששני התנאים מתקיימים. עד אז: `noindex, nofollow`, חסימת סריקה ב־robots ומפת אתר ריקה. כתובות שיתוף משתמשות בדומיין הציבורי גם לפני הפעלת האינדוקס. לאחר הגדרת דומיין נוצרת כתובת canonical; עם אישור התוכן נוצרים גם מפת אתר וקובץ robots המתיר סריקה. אין דומיין מומצא או דירוגים וביקורות מומצאים ב־Schema.

האתר כולל מטא־דאטה בעברית, Open Graph, תמונת שיתוף, Twitter Card ו־Schema מסוג Organization ו־WebSite, עם קישורי sameAs לפרופילים שסופקו. הסיפור מבוסס על הפוסט שבו אסתר מתארת את תחילת היצירה אחרי 7 באוקטובר ובתקופת המילואים. לפני פרסום לציבור נדרשים אישור תוכן סופי, פרטי מכירה ומשלוח והשלמת הצהרת נגישות. ציון Lighthouse מקומי אינו מבטיח דירוג חיפוש או ציון PageSpeed באתר המפורסם.

## בדיקות

```sh
npm run typecheck
npm test
npm run build
npm run test:sharing
npm run preview
# בטרמינל נוסף, כאשר התצוגה פועלת:
npm run test:browser
npm run test:catalog
npm run audit
```

הכלים משתמשים ב־Chrome המקומי דרך Playwright, ללא התקנת דפדפן נוסף. בדיקות הדפדפן מניחות טיוטה חסומה לאינדוקס. נבדקים RTL, נגישות ב־axe, רוחבים 320–1440 פיקסלים, נכונות קישורים, טופס, מקלדת, תפריט נייד, תמונות, חלונות קטלוג, סל פנייה, העדפות תנועה ועמודי המידע. בדיקות WhatsApp אינן שולחות הודעות.

תוצאות וצילומי מסך נשמרים ב־`reports/`, שאינה נכללת במעקב Git. תוצאות הבדיקה האחרונות מפורטות ב־`VALIDATION.md`.
